### superpowers-vs-pocock-skills

**Knowledge Summary:**

This topic captures systematic research comparing two AI-agent "skills" frameworks: Obra's Superpowers (github.com/obra/superpowers) and Matt Pocock's Skills (github.com/mattpocock/skills). It documents each project's capabilities, structure, and methodology, then analyses overlap, divergent approaches, and relative advantages/disadvantages.

**Quick Links:**

**Key Concepts:**
- Agent Skill — A packaged, reusable unit of agent instructions distributed as a `SKILL.md`-based folder.
- SessionStart Hook — A harness lifecycle event Superpowers uses to force its bootstrap into every session; absent entirely from Pocock's Skills repo.
- Model-invoked / User-invoked Skill — Pocock's explicit invocation-class split in frontmatter; has no equivalent in Superpowers.
