# Terms Index

| Term | Short Description |
|------|-------------------|
| [Agent Skill](superpowers-vs-pocock-skills-terms.md#agent-skill) | A packaged, reusable unit of agent instructions distributed as a `SKILL.md`-based folder, loaded and matched by a harness against conversational context. |
| [Model-invoked Skill](superpowers-vs-pocock-skills-terms.md#model-invoked-skill) | A Pocock Skills term for a skill reachable by the model's own judgment or by a human; the default invocation class. |
| [Progressive Disclosure](superpowers-vs-pocock-skills-terms.md#progressive-disclosure) | A pattern keeping `SKILL.md` short, deferring detail to companion reference files loaded only on demand. |
| [SKILL.md](superpowers-vs-pocock-skills-terms.md#skillmd) | The required entry-point filename for an Agent Skill, Markdown with YAML frontmatter plus an instructions body. |
| [SessionStart Hook](superpowers-vs-pocock-skills-terms.md#sessionstart-hook) | A harness lifecycle event fired at session start/clear/compaction that a plugin can hook to inject content before the first message. |
| [User-invoked Skill](superpowers-vs-pocock-skills-terms.md#user-invoked-skill) | A Pocock Skills term for a skill reachable only by a human explicitly naming it, never by model judgment or another user-invoked skill. |
